# GIGAMULTISPRINT — 4PLANET PRODUCTION FACTORY

Goal: turn Founder-approved ideas into persistent, goal-driven, safe autonomous delivery across the 4PLANET portfolio.

## 00 — Protect what exists
- BRAIN remains truth authority.
- TEST KING remains controlled product receiver.
- Factory runtime starts SHADOW and reversible.
- No LIVE, irreversible money/legal/IP actions or autonomous canon promotion.
- Exact write scopes and locks for concurrent work.

Exit: no path by which the factory can silently damage current canon, product or production.

## 01 — Universal Project Contract
Every BUILD-approved project gets the same minimum structure:
WHY / NORTH STAR / USER / GOLD / CURRENT / GAP / GOALS / WBS / DEPENDENCIES / PROOF / CAPITAL / DISTRIBUTION / LEARNING / FOUNDER GATES / PRIORITY CLASS.

AXE owns idea → project conversion. New projects do not become ACTIVE just because they are interesting.

Exit: current active portfolio can be represented without creating a second truth store.

## 02 — Portfolio Scheduler
Implement hourly ranking by:
STRATEGIC VALUE + CRITICAL PATH + DEPENDENCY UNLOCK + DEADLINE + USER/PROOF + CASH/CAPITAL + LEARNING + AGING − RISK − FOUNDER BURDEN − CONCURRENCY COST.

Service levels:
P0 every productive hour; P1 material movement within 24h; P2 within 72h; blocked work gets blocker resolution; incubating/parked do not create filler.

Exit: deterministic conflict-free batch of normally 5–10 work packages.

## 03 — Symphony Orchestra
Persistent specialist sub-agents:
- Product/Design A + B
- Code/QA A + B
- Research/Data
- User/Distribution
- Capital
- Learning
- BRAIN/Control

Parent AXE Conductor remains the only portfolio scheduler. Workers cannot redefine project priority or canon.

Exit: at least 5 independent packages can be dispatched to isolated workers without write collision.

## 04 — Durable Execution
Each selected package runs as its own Cloudflare Workflow:
DISPATCH → EXECUTE → EVIDENCE → EVALUATE → CORRECT/ACCEPT/REJECT/BLOCK → WRITEBACK.

Retries are idempotent. Human gates can pause without blocking unrelated work. Long jobs survive restarts/evictions.

Exit: interrupted jobs recover without duplicate side effects.

## 05 — Bounded Tool Adapters
Connect one safe adapter at a time:
1. Read-only BRAIN portfolio projection.
2. GitHub read + bounded TEST branch write.
3. Browser/visual QA.
4. Research/web/source adapter.
5. Data/source adapter.
6. User/analytics/distribution prep.
7. Capital prep/current authorised low-risk actions.
8. BRAIN writeback with readback and authority checks.

Each adapter has an explicit capability allowlist and denylist. No shared omnipotent credential.

Exit: workers can execute real tasks while remaining fail-closed outside their authority.

## 06 — Evaluator / Material Progress Gate
Nothing counts merely because a worker says DONE.

Product/design: BEFORE → hypothesis → BUILD → AFTER → visual/runtime evaluation.
Code: exact diff + tests/runtime.
Research/data: source/provenance + build/decision consequence.
Capital: stage truth; pipeline ≠ send ≠ award ≠ cash.
Users: pageview ≠ meaningful use.

Exit: every accepted work package has evidence proving a material outcome.

## 07 — Self-Improving Learning Compiler
For each material outcome:
OBSERVATION → EXPECTED vs ACTUAL → EVIDENCE → CAUSE → LESSON → SCOPE → CONFIDENCE → RULE PROPOSAL → REGRESSION/EVAL → NEXT TEST.

Rules:
- one anecdote never becomes global canon;
- project/component/platform/global scopes stay distinct;
- counter-evidence is retained;
- learned rules can expire or be rejected;
- promotion uses existing BRAIN authority and readback.

Exit: prove at least three cases where one project learning measurably improves later work on another comparable project.

## 08 — Project Realisation Loop
Founder flow:
IDEA → AXE challenge/develop → explicit BUILD → Project Contract → autonomous decomposition → queue → multi-agent execution → evaluator → learning → next queue.

AXE only interrupts Founder for irreducible decision, access, judgement or real-world action.

Exit: one new project can move from Founder idea to reviewable prototype/proof package without Founder project-management work.

## 09 — Shadow Portfolio Trial
Run factory beside current Symphony Conductor on current 4PLANET portfolio.
Compare:
- selected work;
- material outcomes/hour;
- stalled ACTIVE projects;
- regression rate;
- rework;
- Founder burden;
- useful learning transfer.

No LIVE actions.

Exit: factory outperforms the current single-run loop without increased truth/safety failures.

## 10 — Controlled Activation
Enable ACTIVE by section, not all at once.
Recommended order:
Research/Data → Code/QA on isolated TEST scopes → Product/Design → User/Distribution prep → Learning/BRAIN writeback → Capital bounded routes.

Production/live/irreversible actions remain separately gated.

## 11 — Continuous Factory Improvement
Daily compiler: strongest learning, repeated failure, new reusable primitive, stale project, queue starvation, Founder burden.
Weekly: portfolio/service-level audit and worker/evaluator performance.
Monthly: adjust scoring weights only from outcome evidence.

North Star: more verified value moved toward 4PLANET goals per unit Founder attention, without lowering truth, quality or safety.
