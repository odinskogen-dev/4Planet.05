## PRIMARY MISSION

Make current 4SAPIEN / Embla materially more useful, obvious and human for a first-time person. The present surface is too much a priority/readiness gate into underlying engines. Turn it into a coherent decision assistant that helps close a real FOOD choice.

Do not create a new app, new product family, new recommendation architecture, second FOOD system, new branch topology or TEST KING mutation. Build only the isolated bounded candidate from the exact base SHA above.

## HUMAN JOB

A normal person should be able to arrive with a food/product choice and complete this loop:

WHAT ARE YOU CHOOSING?
→ minimum necessary input
→ candidate comparison
→ strongest available evidence
→ RECOMMEND / CLARIFY / WITHHOLD
→ decisive reasons
→ material trade-offs
→ UNKNOWN / what would change the answer
→ one clear next action
→ optional source depth
→ lightweight decision/feedback record where current contracts support it.

## MUST PRESERVE

- PERSONAL FIT / HEALTH, MONEY / WALLET and PLANET remain distinct dimensions.
- Allergens and hard constraints override ranking convenience.
- Physical allergen label remains authoritative where required.
- No universal moral score.
- No paid ranking.
- Missing evidence never becomes a positive ranking signal.
- No fabricated health, price, availability, environmental or purchase claims.
- UNKNOWN stays UNKNOWN.
- Preserve useful current FoodIntelligence / PICK / scanner / alternatives capability, but do not expose internal architecture as the primary human journey.

## REQUIRED MULTIPASS EXECUTION

### PASS 01 — DECISION CLOSURE

1. Open with the person's choice/product, not system vocabulary.
2. Ask priority only if the answer genuinely depends on it.
3. Produce useful value as early as possible after minimum input.
4. Make one explicit outcome dominant: RECOMMEND, CLARIFY or WITHHELD / INSUFFICIENT EVIDENCE.
5. Show 2–4 decisive reasons, not an evidence dump.
6. Show material trade-offs and unknowns.
7. Give one concrete next action: keep / replace / compare / inspect label / add / save where truthful and currently supported.
8. Put provenance and source depth behind progressive disclosure.
9. Remove internal readiness language from the main journey unless required for truthful operation.
10. Run the declared tests before moving to Pass 02.

### PASS 02 — HUMAN CRAFT + FRICTION REMOVAL

Treat the Pass 01 implementation as the baseline and inspect it as a first-time human on:
- 390×844 mobile;
- 430×932 mobile;

Then remove the largest remaining friction defects:

Do not do cosmetic churn. Make Pass 02 materially improve comprehension, speed to value and decision closure.

### PASS 03 — ONLY IF MATERIAL DEFECT REMAINS
