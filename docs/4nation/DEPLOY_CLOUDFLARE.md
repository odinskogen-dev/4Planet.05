## What deploys where
4nation.org is a **Worker** (`4planet-nation-live`, file `ops/nation/4nation-live-worker.js`). It proxies ONE immutable
Cloudflare Pages deployment of project `4planet-05` (constant `IMMUTABLE_ORIGIN`) and adds per-path SEO, robots and sitemap.
So deployment is in two steps: (1) Pages artifact, (2) point the Worker at it.

## Step 1 — Pages preview (review candidate)
CLI:
```bash
npm ci && npm run build
npx --yes wrangler@4.128.0 pages deploy dist --project-name 4planet-05 \
  --branch claude-4nation-country-object-01 --commit-hash "$(git rev-parse HEAD)" --commit-dirty=false
```
Dashboard / drag-and-drop alternative: Cloudflare → Workers & Pages → `4planet-05` → Create deployment → upload `dist/` as a preview branch.

Review URLs on the preview (`https://<hash>.4planet-05.pages.dev`):
- `/4nation` — home (globe, search, featured countries, A–Z index)
- `/4nation/country/norway`, `/brazil`, `/japan`, `/kenya` — launch Country Objects
- `/4nation/country/chad` — any other country (renders, noindex on 4nation.org)
- `/4nation/country/japan?mode=atlas&l=unesco-world-heritage` — Atlas mode (shared engine)
- `/4nation/decisions` — the preserved Oslofjord decision case

## Step 2 — 4nation.org (only after audit + Founder go)
1. Take the immutable deployment URL from Step 1 (or from the king/test deployment after merge).
2. In `ops/nation/4nation-live-worker.js` set `IMMUTABLE_ORIGIN` to that URL and `SOURCE_SHA` to the merged commit.
3. Push to `king/test` → workflow `.github/workflows/4nation-discovery-live.yml` deploys the worker and verifies 200, robots, sitemap and `4NATION — Understand any country`.
   Manual equivalent: `npx --yes wrangler@4.128.0 deploy ops/nation/4nation-live-worker.js --name 4planet-nation-live --compatibility-date 2026-09-21 --keep-vars`.

On 4nation.org the app is host-root: `/`, `/country/{slug}`, `/decisions`. `/atlas` on that host still renders the shared ATLAS for iframes (existing App.tsx rule).

## Post-deploy checks (must pass with real data)
- `/country/norway`: population, GDP per person, life expectancy show values **with years**; source drawer opens and shows the series table.
- World Heritage count matches UNESCO for NO/BR/JP/KE (matching is by ISO code or country name in `iso_codes`/`countries` fields — verify, see GPT handoff §Known risks).
- Atlas mode: map renders, layer switches change the iframe, "Open in full ATLAS" opens `https://4planet.org/atlas?...` (or 4planetatlas.com per host rules).
- Sign in → id.4planet.org → returns to the same country URL; header shows "Account".
- `curl -s https://4nation.org/sitemap.xml` lists `/`, `/decisions`, 4 countries. `/country/chad` has `noindex,follow`.
- WebKit run: `PW_EXECUTABLE=… node scripts/nation-visual-qa.mjs <url> qa-out --browser=webkit` (no `--fixture`).

## Rollback
Revert `IMMUTABLE_ORIGIN` + `SOURCE_SHA` in the worker to the previous values (`https://9c7fe142.4planet-05.pages.dev`, `ba354a82…`) and redeploy the worker. The previous decision page remains reachable at `/decisions` in the new build, so a code rollback is a plain `git revert` of the PR.
