# 4PLANET_ LUME PROJECT — PHYSICAL PROJECTION INTERFACE — PROTO 01

## Status
FOUNDER-AUTHORISED PROTOTYPE BUILD / STACKED DEVELOPMENT LINE / NOT A FIFTH PRODUCT / NOT PRODUCTION.

## Purpose
Take the existing 4PLANET Planet Model, SPECIES identity, Living Systems Journey logic and ATLAS context out of the conventional screen and render them as a physical wall/room experience.

LUME PROJECT is an output renderer. It is not a new truth system, a new ecological model or a replacement for ATLAS, SPECIES, Living Systems or NATURE XR.

## Architecture
BRAIN / PLANET MODEL
→ canonical SPECIES / PLACE / SOURCE / RELATIONSHIP / JOURNEY objects
→ NATURE XR / LUME rendering layer
→ PERSONAL DISPLAY or WALL / ROOM OUTPUT
→ presenter/controller input

Camera-recognition LENS ingestion remains a separate future gate. Projection output does not require it.

## First proof
ORCA is the first projection proof because the current code line already contains:
- Orca LUME visual language;
- the reusable Nature Journey renderer;
- canonical Orca scene definitions;
- Bay of Biscay ecosystem/pilot context;
- truth guards around occurrences, population specificity and the ORCA survey corridor.

Jaguar is the second transfer proof. ATLAS is the third: real spatial/data layers projected at room scale.

## PROTO 01 surface
Route: `/lume/project/`

Modes:
- PRESENTER — wall stage plus local control strip.
- WALL — clean projection canvas only.
- CALIBRATION — grid, safe area and corner targets for projector alignment.
- FULLSCREEN — browser fullscreen when supported.

Controls:
- previous / next;
- keyboard arrows and Page Up/Down;
- P toggles wall/presenter;
- C toggles calibration;
- F toggles fullscreen;
- horizontal touch swipe changes scenes.

URL state:
- `?scene=0..5`
- `?mode=presenter|wall`

Reduced-motion preference is respected.

## Truth boundary
Always preserve:
- occurrence records are not live positions;
- source records are not population size;
- a schematic pilot corridor is not an Orca migration track;
- one population's prey or pressure profile cannot be transferred to all Orca populations;
- explanatory visualisation is not a measurement feed;
- PROTO 01 makes no partner-delivery or ecological-outcome claim.

## Projection design grammar
- pure black master surface;
- luminous ice-blue/white visual system for Orca;
- huge typography and minimal wall UI;
- high-contrast linework, grids and source/truth labels;
- no small desktop-card grammar on the wall;
- presenter controls remain off the wall in WALL mode;
- motion is calm, slow and reduced-motion safe.

## Known visual limitation
The PROTO 01 Orca is a hand-coded luminous anatomical/silhouette study, not yet the target photo-derived or 3D Gold Orca. The next visual gate must derive the LUME outline/wireframe from a rights-cleared real Orca master so anatomy is preserved and the projection does not read as an AI illustration.
