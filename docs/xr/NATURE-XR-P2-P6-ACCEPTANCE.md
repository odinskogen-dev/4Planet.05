# 4PLANET NATURE XR — P2–P6 ACCEPTANCE

## Permanent product rule
NATURE XR is a rendering and interaction lens over canonical 4PLANET truth.

`BRAIN / Living Planet Intelligence → SPECIES + Living Systems + pressure/response claims → Nature Scene Adapter → declarative scene layout → Nature Renderer → flat browser / WebXR`

No XR scene may become an independent ecological truth database.

## P2 — physical Quest/WebXR validation
Must be run on a real supported headset over HTTPS.

PASS requires:
- immersive session enters and exits without crash;
- head pose, local floor and controllers/rays behave correctly;
- all truth hotspots are selectable with both controllers;
- text remains readable at intended viewing distance;
- no accidental locomotion or interaction trap;
- no obvious motion sickness trigger in the default journey;
- frame pacing remains subjectively stable through a complete journey;
- flat-browser fallback remains available after headset-specific changes;
- exact headset/browser/build SHA recorded.

P2 cannot be inferred from Playwright or desktop browser tests.

## P3 — premium scene fidelity + rights control
Spatial audio and a 3D Jaguar are separate asset gates.

Every production candidate asset needs:
- creator/rightsholder;
- source URL / acquisition record;
- licence text and commercial/public-web permission;
- derivative/edit permission where needed;
- attribution requirement;
- territorial/time restrictions if any;
- model/audio version and file hash;
- performance budget;
- rollback/replacement path.

3D Jaguar target:
- anatomically credible rather than exaggerated;
- neutral/natural behaviour, no false ecological simulation claim;
- LOD or equivalent performance strategy;
- compressed web delivery;
- mobile/flat fallback;
- animation separated from scientific claims.

Spatial audio target:
- rights-cleared nature recordings;
- layered ambience rather than generic soundtrack;
- positional cues used only where they improve orientation/attention;
- user mute control;
- no claim that the soundscape reconstructs a precise real habitat unless evidence supports it.

## P4 — declarative Nature Renderer
### P4A — renderer
PASS when one reusable renderer can accept a scene object with:
- canonical entity identity;
- environment/media assets;
- spatial layout;
- interaction nodes;
- truth state;
- source;
- boundary;
- DEPENDENCY / PRESSURE / RESPONSE semantics;
- response/solution handoff.

Renderer must contain no Jaguar-specific scientific truth.

### P4B — canonical adapter
PASS when scientific truth displayed in XR is composed from shared SPECIES/Living Systems/pressure/response records rather than copied into scene files.

Scene/layout files may own:
- camera;
- spatial coordinates;
- visual hierarchy;
- labels/navigation copy;
- presentation mode;
- asset choice where rights-cleared.

Scene/layout files must not become the authoritative source for:
- species identity;
- ecological relationships;
- pressure claims;
- evidence states;
- scientific sources;
- uncertainty/boundaries;
- solution-effectiveness claims.

## P5 — classroom + museum modes
Both must be presets over the same renderer and canonical truth feed.

Classroom mode:
- teacher-led pause/advance;
- visible learning objectives;
- source/evidence inspection;
- short guided sequence;
- comprehension prompts;
- browser-first operation without a headset.

Museum mode:
- attract loop / idle reset;
- durable kiosk controls;
- short self-contained journey;
- accessible text/audio alternatives;
- no account requirement;
- privacy-safe anonymous instrumentation only after approval.

No forked classroom or museum truth database.

## P6 — measured learning and AWE
Do not claim learning, AWE or referral effect before actual tests.

Minimum pilot measures:
- comprehension: can a person correctly explain 2–3 core relationships/pressures?;
- recall: what remains after a delay?;
- source behaviour: did they inspect evidence or uncertainty?;
- completion: did they finish the intended journey?;
- AWE/self-report: short bounded post-experience rating, clearly subjective;
- referral: would/share/did-share behaviour, separated from intention;
- device/mode: flat browser vs headset vs classroom/museum context.

Use a pre-defined test protocol and preserve raw response boundaries. Do not optimise only for dwell time.

## Promotion rule
A successful branch preview is not production authority. Promotion to 4planet.org requires exact accepted SHA, green CI, rights/source review, flat-browser verification, mobile verification, rollback readiness and explicit current release authority.
