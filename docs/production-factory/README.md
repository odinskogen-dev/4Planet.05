## Runtime loop

1. Recover current portfolio projection.
2. Score ACTIVE work against strategic value, critical path, dependency unlock, deadline, proof, cash, learning, aging, risk, founder burden and concurrency cost.
3. Build a conflict-free hourly batch.
4. Dispatch durable work packages to specialist sections.
5. Require evidence and evaluate outcomes.
6. Capture scoped learning candidates.
7. Re-rank and continue.

## Default service levels

- P0 / CRITICAL: eligible every productive hour while unblocked.
- P1 ACTIVE: material progress within rolling 24h or explicit blocker / evidence-based reprioritisation.
- P2 ACTIVE: material progress within rolling 72h or explicit blocker / evidence-based reprioritisation.
- BLOCKED: attempt blocker resolution or surface smallest irreducible Founder/external gate.
- INCUBATING: bounded research/modelling only.
- PARKED: no autonomous capacity.
