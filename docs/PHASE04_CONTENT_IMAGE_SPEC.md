# 4PLANET_ PHASE 04 — CONTENT + IMAGE SYSTEM

Status: **INTERNAL SPEC / RIGHTS-AWARE / NO GENERATED DOCUMENTARY EVIDENCE**

## Governing rule

**Life carries emotion. Product behaviour carries distinctiveness. Proof carries trust.**

Images may create attention and attachment. They must never silently create evidence.

Every used or proposed visual receives one class:

- `OWNED` — 4PLANET/Odin-owned with documented rights.
- `LICENSED` — licensed from a third party with scope recorded.
- `OPEN` — public-domain/open-licence asset with attribution/terms recorded.
- `SOURCE-DERIVED` — comes from a source record and inherits source/record rights and limitations.
- `GENERATED` — synthetic/illustrative; never presented as documentary field evidence.
- `PLACEHOLDER` — temporary composition aid; not releasable.

## Critical front-door gap

The Phase 04 front-door hypothesis is **Living Place-first**, but the repository does not currently expose a rights-controlled, verified Oslofjorden-specific documentary hero that can safely function as both emotional protagonist and place truth.

The File Library search for `Oslofjorden photo / documentary photography` did not surface a clear owned/licensed Oslofjorden hero asset; it surfaced product/source documents instead.

Therefore:

**DO NOT solve this gap with generated documentary imagery or by relabelling a generic ocean image as Oslofjorden.**

### Preferred final hero acquisition order

1. `OWNED` — Odin/4PLANET real Oslofjorden photography, if suitable and rights-clean.
2. `LICENSED` — high-end documentary still with clear commercial/web rights.
3. `OPEN` — public-domain/CC asset only if quality and attribution requirements fit the premium system.
4. `SOURCE-DERIVED` — only when the source image is legitimately tied to the shown record and display rights permit it.
5. `GENERATED` — permitted only as clearly stylised conceptual art, never as a factual Oslofjorden photograph/observation.

## Oslofjorden journey image map

### PLACE
- real aerial/coastal/shore frame if rights exist;
- map/geometry is data, not decoration;
- show semantic place identity separately from management/waterbody/display geometry.

### LIFE
- source-derived species imagery only if image rights inherit cleanly from the source record;
- occurrence photography must not imply abundance or current position;
- if no rights-clean local image exists, use a species profile handoff rather than a decorative substitute.

### RELATIONSHIP
- product-generated diagram/interaction, not pseudo-scientific infographic art;
- every causal-looking edge requires status/source semantics.

### PRESSURE
- data visual/diagram preferred over disaster stock photography;
- photographs of wastewater/agriculture/boats/etc. must be contextual, not accusatory evidence about a specific actor.

### SIGNAL
- typography + source/time + small place/source visual where useful;
- do not turn Signal into a news-card feed.

### ACTORS / SOLUTIONS
- logos/photos only with appropriate usage rights and scope;
- appearing in the graph does not imply partnership or endorsement.

### ACTION / PROOF
- field images may accompany an actual documented activity;
- activity photo ≠ outcome proof;
- before/after requires same-place/method/time semantics and explicit limitations.

- asset ID;
- file/source URL;
- creator;
- rights holder;
- licence;
- permitted commercial/public use;
- attribution string;
- derivative/crop permission;
- expiry if licensed;
- source record ID if source-derived;
- location/event claim allowed by evidence;
- sensitivity restrictions;
- approval state.
