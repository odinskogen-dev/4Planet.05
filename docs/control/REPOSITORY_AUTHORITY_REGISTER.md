## Separate active operational projects

A Project Home may legitimately use another repository or deployment surface for a bounded operational reason. That does **not** create a second 4PLANET public-product convergence authority. Before continued material code, the Project Home must record the repository, exact line, WHY, relationship to TEST KING, shared contracts, release boundary and GOLD inheritance.

## New repository rule

A new 4PLANET repository is **NOT AUTHORISED FOR MATERIAL USER-FACING DEVELOPMENT** merely because it has been created.

Before material work it must have:
1. BRAIN / Project Home owner;
2. WBS mapping;
3. product seam and WHY;
4. explicit reason the work cannot live in `4Planet.05`;
5. parent/code lineage and exact rollback identity;
6. relation to TEST KING: `INTEGRATED | ISOLATED EXPERIMENT | OPERATIONAL SEPARATE`;
7. canonical GOLD authority reference;
8. GOLD pre-code brief mechanism;
9. required test/render/truth/accessibility gates;
10. return/adoption path.

If those are absent, treat the repository as `UNREGISTERED CANDIDATE` and do not use it as an active public-product line.
